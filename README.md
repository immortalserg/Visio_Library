# Библиотека фигур Visio

Открытая библиотека мастеров и трафаретов Microsoft Visio и инструменты для анализа и сопровождения зависимых фигур.

## Структура

- `test/` — тестовые библиотеки VSSX и распакованные копии;
- `src/` — исходный код;
- `tests/` — автоматические тесты;
- `tools/` — вспомогательные инструменты;
- `schemas/` — схемы форматов;
- `examples/` — примеры;
- `docs/` — документация.

## Правила разработки

Документация ведётся на русском языке. См. [правила разработки](docs/ПРАВИЛА_РАЗРАБОТКИ.md).
